A gradient softening plasticity was implemented in the open-source [MOOSE](https://mooseframework.inl.gov/) finite element code. The nice thing about MOOSE is that it provides an interface for using 3D constitutive models developed using the Abaqus UMAT subroutine. An example deformation is shown below.

The code is simple.
Just wrap your images with `<div class="col-sm">` and place them inside `<div class="row">` (read more about the <a href="https://getbootstrap.com/docs/4.4/layout/grid/">Bootstrap Grid</a> system).
To make images responsive, add `img-fluid` class to each; for rounded corners and shadows use `rounded` and `z-depth-1` classes.
